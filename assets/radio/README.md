# Nhạc do người dùng cung cấp

Thêm MP3, WAV, OGG hoặc M4A bằng **+ Thêm file** trong Studio, hoặc chép vào đây rồi bấm **Tải lại** trong thư viện.

Tích bài nào thì người xem thấy mã `!nhac` của bài đó trên overlay. Bỏ tích để ẩn; bài đang chờ bị gỡ và bài đang phát bị dừng nếu bị bỏ tích. **Sửa tên** để chỉnh tên hiển thị.

Repo không kèm bài hát thương mại. Các file ở đây được `.gitignore` bỏ qua; chỉ README được theo dõi. Sử dụng nhạc bạn có quyền phát/chia sẻ. Nhạc nền mặc định được tổng hợp bằng Web Audio, không cần file.

Mã bài có thể đổi khi các bài được tích thay đổi; dùng mã đang hiện. Mặc định một người có một phiếu trong hàng chờ.
